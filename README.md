# Content-driven UI Platform

A content-driven frontend platform built with Next.js, TypeScript and Tailwind CSS.

## Goals

- Build reusable UI components
- Render pages from structured content
- Explore component architecture
- Practice accessibility
- Practice testing
- Measure and improve performance
- Experiment with A/B testing

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vitest
- React Testing Library
- Playwright
- Storybook
